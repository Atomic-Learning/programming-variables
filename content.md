In programming, variables are used to reference data stored in memory. The variable name is written within the source code of the program for the purposes of writing to or retrieving the value stored in that location. For example, the pseudocode below shows how a variable might be used to store a number and then display it.

```
// Declare a variable called "age" and store the number 25 in it
age = 25
// Display the value stored in the variable "age"
print(age)
```

Different languages will have different rules for acceptable variable names and how variables are declared and used.
